# Review rubric

`rubric.md` was written by an independent review agent before it saw the design, from the literature survey. It is unedited; `rubric.sha256` is its SHA-256 (`sha256sum -c rubric.sha256`). Changes after the work was seen are only appended to `rubric-amendments.md`.

The rubric refers to the survey and bibliography as `survey.md` and `bibliography.md`; in this repository they are [language-service-survey.md](../language-service-survey.md) and [language-service-bibliography.md](../language-service-bibliography.md).
